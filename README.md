# flight_delays_eda

# ✈️ Flight Delays — Exploratory Data Analysis

## 📌 Overview

This project focuses on **Exploratory Data Analysis (EDA) of flight delays and cancellations** in the United States.

The goal is to explore flight data, identify patterns, and investigate factors associated with delays using data analysis and visualization techniques.

## 🎯 Objectives

- Explore and understand the flight dataset.
- Perform data cleaning and preprocessing.
- Analyze the distribution of flight delays.
- Identify patterns and trends in flight operations.
- Compare delay patterns across airlines and airports.
- Investigate the relationship between departure and arrival delays.
- Visualize key findings and extract meaningful insights.

## 📂 Dataset

The dataset used in this project is **2015 Flight Delays and Cancellations**, provided by the U.S. Department of Transportation and available on Kaggle.

🔗 **Dataset link:** [Flight Delays and Cancellations — Kaggle](https://www.kaggle.com/datasets/usdot/flight-delays/data)

The dataset contains information about U.S. domestic flights in 2015, including flight schedules, airlines, airports, delays, and cancellations.

The dataset includes three main files:

- `flights.csv` — Flight information, schedules, and delay data.
- `airlines.csv` — Airline names and their corresponding codes.
- `airports.csv` — Airport names, codes, and geographical information.

**Note:** The dataset is not included in this repository. Download it directly from Kaggle and place the required files in the appropriate directory before running the analysis.

## 🛠️ Tools & Technologies

- **Python** — Data analysis and processing.
- **Pandas** — Data manipulation and analysis.
- **NumPy** — Numerical computations.
- **Matplotlib** — Data visualization.
- **Seaborn** — Statistical data visualization.
- **Jupyter Notebook** — Interactive analysis.

## 🔍 Methodology

The project follows an exploratory data analysis workflow:

1. **Data loading:** Import the dataset into Python.
2. **Data inspection:** Examine the structure, data types, and descriptive statistics.
3. **Data cleaning:** Identify missing values, duplicates, and inconsistencies.
4. **Exploratory analysis:** Investigate flight delays and cancellations.
5. **Data visualization:** Create charts to identify patterns and trends.
6. **Insights:** Interpret the findings and summarize relevant observations.

## 📊 Analysis

The analysis explores flight delay patterns through different perspectives, including:

- Distribution of departure and arrival delays.
- Flight delays by airline.
- Delay patterns across days of the week and months.
- Differences between departure and arrival delays.
- Flight cancellations and their distribution.
- Relationships between selected numerical variables.

The analyses performed depend on the variables and data available in the dataset.

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 and Jupyter Notebook are installed.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kingvieira10/flight_delays_eda.git
```

**2. Navigate to the project directory**

```bash
cd flight_delays_eda
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Download the dataset**

Download the CSV files from [Kaggle — Flight Delays](https://www.kaggle.com/datasets/usdot/flight-delays/data).

**5. Run the notebook**

```bash
jupyter notebook
```

Open the project notebook and execute the cells to reproduce the analysis.
